서비스 범위

마케팅 서비스의 구체적인 범위, 일정, 결과물은 상담 및 견적 단계에서 협의한 내용을 기준으로 합니다. 서비스 범위에는 브랜드 진단, 콘텐츠 운영, 광고 운영, 인플루언서 마케팅 운영, 마케팅 컨설팅과 교육이 포함될 수 있습니다.

Influencer CRM 베타 기능은 인플루언서 후보 관리, 캠페인 일정 관리, 협업 상태 관리, 콘텐츠 링크 기록, 내부 메모, 반응 관련 기록 정리를 돕는 운영 보조 기능입니다.

사용자의 책임

  • 사용자는 정확한 문의 및 계정 정보를 제공해야 합니다.
  • 사용자는 본인이 권한을 가진 계정만 연결할 수 있습니다.
  • 사용자는 Instagram, Facebook, Meta 등 제3자 플랫폼의 정책과 관련 법령을 준수해야 합니다.

Meta / Instagram 기능 제한

Instagram and Meta-related features are provided only within Meta-approved API permissions, connected Professional account authorization, and Meta platform policies. Some features may be limited or changed depending on Meta API approval status and policy changes.

금지된 이용

본 서비스는 승인되지 않은 스크래핑, 무단 데이터 수집, 자동 대량 콜드 DM 발송, 모든 Instagram 계정의 자유 분석, 개인정보의 부적절한 이용, 플랫폼 정책 우회, 승인된 Meta API로 지원되지 않는 자동 팔로우 상태 검증을 제공하거나 허용하지 않습니다.

베타 / MVP 기능 변경

Influencer CRM은 현재 베타 또는 MVP 단계이며, 일부 기능은 테스트 결과, 운영 필요, Meta API 승인 상태 또는 정책 변경에 따라 변경, 제한, 중단될 수 있습니다.

지식재산권

별도 합의가 없는 한 서비스 과정에서 제공되는 기획안, 문서, 콘텐츠의 사용 범위는 프로젝트 협의 내용에 따릅니다.
